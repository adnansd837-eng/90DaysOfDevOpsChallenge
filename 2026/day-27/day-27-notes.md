# Day 27 – GitHub Profile Makeover

## What I Learned

Today I worked on improving my GitHub profile.

I understood that GitHub is like a developer portfolio where I can show my projects, skills, and learning journey.

---

## Task 1 – Check My GitHub Profile

First, I checked my GitHub profile as if I was a recruiter.

I checked:

- Profile picture
- Bio
- Repository names
- Repository descriptions
- Pinned repositories
- README files

### What I noticed

Some of my repositories needed better names, descriptions, and documentation.

My goal was to make my profile clean and easy to understand.

---
